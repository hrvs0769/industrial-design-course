# 工业设计 · 一学期 16 课

面向大学工业设计专业的**课堂互动课件**。每一课都从一件真实的实物开始，最后一定落到学生自己动手。

### 👉 在线打开：<https://hrvs0769.github.io/industrial-design-course/>

## 这套课件长什么样

![课程地图](.github/map.png)

**16 课，51 处课堂互动，80 道随堂题，21 件真实实物照片。**

| | | |
|---|---|---|
| 01 设计是什么 | 02 观察力 | 03 设计史 |
| 04 人机工程 | 05 草图是思考 | 06 材料与工艺 |
| 07 结构与成本 | 08 定义问题 | 09 形态与语义 |
| 10 CMF | 11 失败博物馆 | 12 可持续设计 |
| 13 从物件到界面 | 14 AI 与设计 | 15 设计师的一天 |
| 16 学生作品展 | | |

每课都是同一副骨架：**先看见实物 → 再讲透一个概念 → 最后一定落到学生自己动手。**
里面有抽题画板、5 分钟计时器、可拖动的设计光谱、九个节点的设计史时间轴、白墙展厅式的实物陈列、以及每课 5 道带解析的随堂题。

## 三个特点

**1. 断网也能放。**
21 张照片、全部图形与字体都已本地化，零外部请求。把整个文件夹拷进 U 盘，插到任何一台教室电脑上双击 `index.html` 就能用。

**2. 为投影而做。**
`→` 翻节、`N`/`P` 翻课、`T` 开计时、`R` 随机抽一件实物、`?` 看全部快捷键。计时器启动后浏览器标签页标题会同步倒计时，切去开 PPT 也能看见还剩多久。

**3. 内容与渲染分离。**
每课的全部文字都在 `assets/data/NN.js` 一个文件里，改文案不用碰任何其它文件。16 课共用一套设计系统和互动组件库。

```
工业设计/
├── index.html              课程地图（首页）
├── lessons/                16 个课程页面
├── assets/
│   ├── data/01.js … 16.js  每课的全部内容 ← 备课只改这里
│   ├── render.js           区块渲染引擎
│   ├── labs.js             互动组件库
│   ├── lesson-shell.js     页面外壳
│   ├── objects.js          10 件实物的故事
│   └── img/                21 张 WebP 照片
└── 使用说明.md              完整使用与备课说明
```

## 本地使用

```bash
git clone https://github.com/hrvs0769/industrial-design-course.git
cd industrial-design-course
open index.html          # macOS
# 或者起个本地服务：python3 -m http.server 8000
```

双击 `index.html` 即可，不需要联网，不需要构建，不需要安装任何依赖。
